# FileForge — Python File Manager (Streamlit UI)

A dashboard for a simple Python file handling project: create, read, update (rename / append / overwrite) and delete files.

## Run it

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open http://localhost:8501 in your browser.

All files are stored in the `workspace/` folder next to `app.py`.
Click **Load sample files** in the sidebar to fill the dashboard for a screenshot.
